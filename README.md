# 🤖 AI-Sysadmin: Локальный ИИ-агент через телеграмм бота и терминал для диагностики Linux.

Автономный ИИ-агент с **историей диалога**, который анализирует проблемы на Linux-сервере, самостоятельно выполняет диагностические команды и выдает готовый отчет.

Работает **полностью локально** через Ollama — без API-ключей, без отправки данных в облако, бесплатно.

## 🛠 Стек технологий
- **Язык**: Python 3
- **ИИ-модель**: Qwen 2.5 (через Ollama)
- **Архитектура**: Router Agent паттерн + Tool Calling
- **ОС**: Linux (Ubuntu/Debian)

## ⚡ Возможности
- ✅ **История диалога** — агент помнит контекст разговора
- ✅ **Router Agent** — сам решает, нужна ли команда или просто ответ
- ✅ **Анализ диска** (`df -h`)
- ✅ **Проверка памяти** (`free -h`)
- ✅ **Диагностика сети** (`ss -tulnp`)
- ✅ **Статус сервисов** (`systemctl is-active`)
- ✅ **Чтение логов** (`tail`)
