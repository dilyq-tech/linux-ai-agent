# 🤖 AI-Sysadmin Bot

Умный Telegram-бот для мониторинга Linux-серверов с AI-анализом метрик.

## 🚀 Возможности

### 📊 Мониторинг
- **Статус серверов** — CPU, RAM, Disk в реальном времени
- **Процессы** — топ процессов по потреблению RAM
- **Сеть** — трафик и скорость передачи данных
- **Система** — аптайм, load average, информация о загрузке

### 🧠 AI-анализ
- Анализ трендов нагрузки через **Qwen 2.5:3b** (локально через Ollama)
- Выявление аномалий и рекомендации по оптимизации
- Работает без интернета (локальная модель)

### 🔍 Диагностика
- **Поиск ошибок** — фильтрация системных логов на наличие error/failed/critical
- **Авторизация** — отслеживание попыток входа (SSH, sudo)
- **Логи сервиса** — последние логи ai-sysadmin
- **Активные сервисы** — список running systemd-служб

### 🛡️ Безопасность
- Алерты при превышении порогов CPU/RAM/Disk
- Уведомления в Telegram
- Автоматическая очистка старых метрик из БД

## 📦 Установка

### Требования
- Python 3.8+
- Ollama (для AI-анализа)
- Telegram Bot Token
- VPN-клиент с прокси на порту 12334 (опционально)

### Быстрый старт

```bash
# Клонируй репо
git clone https://github.com/dilyq-tech/linux-ai-agent.git
cd ai-sysadmin

# Создай виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установи зависимости
pip install -r requirements.txt

# Настрой переменные окружения
cp .env.example .env
nano .env  # укажи BOT_TOKEN и ADMIN_ID

# Запусти Ollama (для AI)
ollama serve &
ollama pull qwen2.5:3b

# Запусти бота
python main.py
